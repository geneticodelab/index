# Geneticode Lab

Jekyll site for [Geneticode Lab](https://geneticode.org): Home, Research, People, Publications, News, and Contact. GitHub Pages can build it with the allowlisted plugins in `_config.yml`.

Editable content lives in `_data/` (lab profile, members, research, publications, news) and in the Markdown pages plus `_posts/`. `CNAME` is `geneticode.org`.
